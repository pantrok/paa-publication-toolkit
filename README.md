# PAA Publication Toolkit

Toolkit desarrollado específicamente para generar automáticamente las figuras, tablas y recursos gráficos del artículo:

**Evaluation Protocols for Infant Cry Classification Using Acoustic Pattern Representations**

Revista objetivo:

**Pattern Analysis and Applications (Springer)**

---

## Objetivos

- Generar figuras con calidad editorial Springer.
- Exportar PDF vectorial, SVG y PNG (600 dpi).
- Generar tablas compatibles con `sn-jnl.cls`.
- Automatizar captions.
- Automatizar reportes de resultados.
- Facilitar la actualización cuando cambien los CSV.
